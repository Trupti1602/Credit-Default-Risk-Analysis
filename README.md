# Credit Default Risk Analysis using SQL, Python & Power BI

## Project Overview

This project analyzes credit card customer data to identify patterns associated with payment defaults. It uses SQL for data analysis, Python for data cleaning and exploratory data analysis (EDA), and Power BI for interactive visualization.

The goal is to understand how customer characteristics, credit limits, and historical payment delays relate to observed credit default risk.

## Business Problem

Credit risk teams need to understand which customer segments show higher rates of payment default. This project explores historical customer data to identify useful patterns and communicate findings through a dashboard.

**Key questions:**

- What proportion of customers defaulted?
- How do observed default rates vary by gender, education, and age group?
- How are credit limits associated with default rates?
- How do historical payment delays relate to default rates?

## Tools & Technologies

- **SQL / MySQL:** Data validation, aggregation, grouping, and risk analysis
- **Python:** Pandas, NumPy, Matplotlib, Seaborn
- **Power BI:** KPI cards, charts, slicers, and dashboard design
- **Git & GitHub:** Version control and project sharing

## Dataset

The project uses the UCI Machine Learning Repository's _Default of Credit Card Clients_ dataset.

- Original dataset size: 30,000 customer records
- Original attributes: 25
- Target: Default
